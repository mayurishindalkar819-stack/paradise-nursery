# Paradise Nursery Shopping Application

A React-based online plant shopping application for the Paradise Nursery final project.

## Features
- Landing page with background image and Get Started button
- Plant listing with 18 plants in 3 categories
- Add-to-cart functionality with disabled Add to Cart buttons
- Dynamic cart quantity
- Shopping cart with increase, decrease, delete, total cost
- Checkout and Continue Shopping buttons
- Redux Toolkit state management
- React Router navigation

Paradise Nursery Shopping Application
